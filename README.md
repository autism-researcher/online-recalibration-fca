# A Safety Clamp for Adaptive Forward-Collision
Avoidance in Intelligent Vehicles

Code, derived results, and figures for the paper *"A Safety Clamp for Adaptive Forward-Collision Avoidance in Intelligent Vehicles"*
(M. B. Hossain, M. A. S. Kamal, and K. Yamada, submitted to
*IEEE Transactions on Intelligent Vehicles*, 2026).

A data-driven forward-collision-avoidance (FCA) supervisor intervenes when a bounded risk
score crosses a calibrated boundary. Once the driving distribution shifts, a fixed boundary
no longer holds the operator's target intervention rate. This repository implements the
online recalibration of that boundary, the slow finite-sample-banded **safety clamp** that
bounds transient under-protection by construction, and the experiments that evaluate them on
naturalistic driving data and in closed-loop CARLA conflicts.

## Data availability

The experiments use three naturalistic driving corpora obtained from their providers under the
respective terms of use:

- **highD** — Institute for Automotive Engineering (ika), RWTH Aachen University, via levelXdata
- **NGSIM** — U.S. Federal Highway Administration
- **Waymo Open Motion Dataset** — Waymo LLC

**These datasets are licensed and are NOT redistributed in this repository.** To reproduce the
results, obtain the datasets from their providers and point the scripts at your local copy
(`--root` argument). This repository contains only the code, the small derived result files
(JSON/CSV), and the figures. The per-step feature and TTC streams are likewise not
redistributed; the code regenerates them from provider-obtained data, and they are needed
only for the fixed-TTC AEB arm of the composite safety panel.

## Repository layout

```
scripts/      analysis and experiment code
  full_hardware_run.py          main 547-segment harness (all methods, tables, figures)
  reconcile_safety_panel.py     single-pass TTC danger panel (counts + missed-danger)
  density_check.py              density of the risk score at the boundary (Prop. 1 assumption)
  within_corpus_baseline.py     per-segment train/test fixed-boundary baseline
  baselines_dtaci_saocp.py      DtACI / SAOCP-style comparators (rate-objective adaptations)
  ngsim_denoise_sensitivity.py  NGSIM low-pass cutoff robustness
  carla_experiment/             closed-loop CARLA validation harness
code/         supervisor, clamp, and SSM validation implementations
results/      derived result files (JSON) regenerated by the scripts
Results_1/    SSM panel CSVs (per-corpus missed-danger / false-alarm)
cs_*.csv      per-seed controlled-conflict outcomes (lead-brake, cut-in, crossing)
figures/      figures used in the paper
```

**Authoritative artifacts:** the derived results that back the submitted manuscript's
tables are the verification-run JSONs regenerated by `full_hardware_run.py`
(547 segments: HighD 117 + NGSIM 400 + Waymo 30). Any older result files reflecting
subset runs (e.g., 429- or 143-segment exploratory passes) are superseded.

## Reproducing the results

```bash
pip install numpy matplotlib sortedcontainers
# point --root at your local copy of the frozen feature pipeline
python scripts/full_hardware_run.py        --root /path/to/pipeline --corpora highd ngsim waymo
python scripts/reconcile_safety_panel.py   --root /path/to/pipeline --corpora highd ngsim waymo
python scripts/density_check.py            --root /path/to/pipeline --corpora highd ngsim waymo
python scripts/within_corpus_baseline.py   --root /path/to/pipeline --corpora highd ngsim waymo
```

## Key results (547 naturalistic segments; HighD + NGSIM + Waymo)

- The online update holds the time-averaged intervention rate near target (deviation 0.0032),
  an order of magnitude or more below fixed (0.146), batch (0.131), and change-point-gated
  (0.063) baselines — and below fixed and batch on every one of the 547 segments.
- The same update leaves a large transient under-protection (per-segment worst case 0.363);
  the safety clamp cuts it to 0.106–0.135 (63–71%) at a modest, tunable rate cost.
- Independent surrogate panel (TTC/DRAC): the online update misses 17–34% of danger events;
  the clamp misses 1–3%.
- Controlled closed-loop CARLA conflicts: the clamp eliminated all observed collisions
  (0, against the online update's 42 across the two conflict-producing scenarios).
- The estimated risk-score density at the boundary exceeds 0.86 on every segment
  (per-corpus minima 1.83 / 0.86 / 1.21), satisfying the assumption of the
  under-protection bound.
