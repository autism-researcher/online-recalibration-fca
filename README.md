# Online Recalibration of FCA Supervisors with a Bounded Transient Under-Protection Guarantee

Code, derived results, and figures for the paper *"Online Recalibration of
Forward-Collision-Avoidance Supervisors with a Bounded Transient Under-Protection
Guarantee"* (M. B. Hossain and M. A. S. Kamal, submitted to IEEE T-ITS, 2026).

A data-driven forward-collision-avoidance (FCA) supervisor intervenes when a bounded risk
score crosses a calibrated boundary. Once the driving distribution shifts, a fixed boundary
no longer holds the operator's target intervention rate. This repository implements the
online recalibration of that boundary, the slow finite-sample-banded **safety clamp** that
bounds transient under-protection by construction, and the experiments that evaluate them on
naturalistic driving data.

## Data availability

The experiments use three naturalistic driving corpora obtained from their providers under the
respective terms of use:

- **highD** — Institute for Automotive Engineering (ika), RWTH Aachen University, via levelXdata
- **NGSIM** — U.S. Federal Highway Administration
- **Waymo Open Motion Dataset** — Waymo LLC

**These datasets are licensed and are NOT redistributed in this repository.** To reproduce the
results, obtain the datasets from their providers and point the scripts at your local copy
(`--root` argument). This repository contains only the code, the small derived result files
(JSON), and the figures.

## Repository layout

```
scripts/      analysis and experiment code
  reconcile_safety_panel.py     single-pass TTC danger panel (counts + missed-danger)
  density_check.py              density of the risk score at the boundary (Prop. 1 assumption)
  within_corpus_baseline.py     per-segment train/test fixed-boundary baseline
  paper4_realdata_harness.py    online/batch/CUSUM recalibration harness
  carla_experiment/             closed-loop CARLA validation harness
results/      derived result files (JSON) regenerated by the scripts
figures/      figures used in the paper
```

## Reproducing the results

```bash
pip install numpy matplotlib sortedcontainers
# point --root at your local copy of the Paper-3 feature pipeline
python scripts/reconcile_safety_panel.py   --root /path/to/paper3_pipeline --corpora highd ngsim waymo
python scripts/density_check.py            --root /path/to/paper3_pipeline --corpora highd ngsim waymo
python scripts/within_corpus_baseline.py   --root /path/to/paper3_pipeline --corpora highd ngsim waymo
```

## Key results (naturalistic data; HighD + NGSIM + Waymo)

- The online update holds the time-averaged intervention rate near target (deviation ~0.003),
  more than an order of magnitude below fixed, batch, and change-point-gated baselines.
- A fixed boundary calibrated **per recording** on a held-out split still loses by ~70x (HighD)
  and ~22x (NGSIM): the gap is genuine within-recording drift, not global-calibration artifact.
- TTC < 1.5 s danger panel: online misses ~34% of low-TTC events; the clamp ~1.2%.
- The density of the risk score at the boundary stays above 0.8 across all segments
  (measured minimum 0.86), satisfying the assumption of the under-protection bound.
